# Todo List (React)

Vanilla JS로 작성된 1차 과제를 React로 마이그레이션한 Todo 앱입니다.

## 기술 스택

- React 19, Vite, Tailwind CSS v4

## 구현 기능

### Todo CRUD
- 텍스트 입력 후 추가 버튼 또는 Enter 키로 Todo 생성
- 빈 값 입력 시 안내 메시지 표시
- 인라인 입력창으로 수정 (Enter 저장 / Escape 취소)
- 완료 처리 시 취소선으로 시각적 구분
- 삭제

### 필터링
- 전체 / 진행 중 / 완료 탭으로 상태별 필터링

### 일간 뷰
- 이전/다음 버튼으로 날짜 이동
- Todo 생성 시 현재 선택된 날짜에 자동 저장
- 날짜별로 독립적인 Todo 목록 관리

### 주간 뷰
- 이번 주 7일 달력 표시
- 날짜 클릭 시 해당 날짜로 이동
- 이전/다음 주 이동
- 각 날짜 아래 Todo 개수 표시
- 오늘 날짜 강조 표시

### 데이터 유지
- `localStorage`에 자동 저장, 새로고침 후에도 데이터 유지
- 선택한 날짜 및 주차도 새로고침 후 유지
